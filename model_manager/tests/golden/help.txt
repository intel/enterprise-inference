model-manager — Deploy LLM inference models on Kubernetes

Commands:
  deploy <model>|--id <hf/repo>   Download weights + deploy serving pod
  cpu-collisions-check            Report CPU pinning, NUMA layout & detect core collisions
  undeploy <model>|<name>|all     Remove pod (keeps weights on PVC); accepts a catalog model, an --as alias, or any deployed name

Deploy Options:
  --id <hf/repo>       Ad-hoc deploy any HuggingFace model
  --name <name>        Override generated name (with --id)
  --server <name>      Model server/engine: vllm (default) | openvino  (alias: --runtime)
  --server-version V   Server version (must be declared for the model if it uses servers:)
  --as <name>          Deploy under a distinct name (run multiple server/version variants at once)
  --cpu N              CPU cores
  --memory NGi         Memory (e.g. 32Gi)
  --replicas N         Replica count (default: 1)
  --tp N               Tensor-parallel size (splits across N NUMA nodes)
  --cpu-policy <p>     CPU pinning: nri-balloons | kubelet-static | best-effort
                            (default: MM_CPU_POLICY, else auto-detected)
  --category <cat>     Override category: llm | embed | rerank | vlm
  --routing <mode>     Override routing: epp | aigateway | direct
  --node <name>        Pin deployment to a specific node
  --env KEY=VAL        Add/override env var (repeatable)
  --arg "--flag=val"   Append a runtime arg (repeatable)
  --label KEY=VAL      Add a metadata label to the serving CR (repeatable);
                            use it to mark ownership — managed-by=model-manager
                            is set for every caller and cannot distinguish them
  --wait               deploy: block until model is Ready; undeploy: block until pods terminate
  --wait-timeout N     Seconds to wait (default: deploy 900, undeploy 180)
  --dry-run            Print manifest without applying

Examples:
  ./model-manager deploy llama3-8b-awq --wait
  ./model-manager deploy llama3-8b-awq --server-version 0.19.1 --wait
  ./model-manager deploy --id meta-llama/Llama-3.2-1B-Instruct --cpu 8 --memory 16Gi
  ./model-manager undeploy llama3-8b-awq
  ./model-manager undeploy llama3-8b-awq --wait        # block until pods terminate + CPUs are freed

For status / scale / logs, use kubectl:
  kubectl get llminferenceservices,inferenceservices -n llm-inference
  kubectl patch llminferenceservice <name> -n llm-inference -p '{"spec":{"replicas":N}}'
  kubectl logs -n llm-inference -l app.kubernetes.io/name=<name> -f

Environment:
  HF_TOKEN              HuggingFace token for gated models
  MM_CONFIG             Path to models.yaml
  MM_CPU_POLICY         Cluster CPU policy: nri-balloons (default) |
                        kubelet-static | best-effort. Set by the Ansible
                        install from kubernetes_cpu_policy; --cpu-policy wins.
  MM_NRI_ENABLED        Legacy: false ⇒ best-effort (no pinning)
  MM_PREFLIGHT          'warn' ⇒ report placement failures, don't block
  MM_SKIP_PREFLIGHT     1 ⇒ skip the placement pre-flight entirely
  MM_INFERENCE_HOSTNAME Override inference gateway hostname

CPU policies:
  nri-balloons    (default) NRI balloons plugin — NUMA-aware balloons sized
                  per TP shard. Requires the nri_cpu_balloons Ansible role.
  kubelet-static  kubelet static CPU manager — pods are rendered as
                  Guaranteed QoS (integer cpu, requests == limits) so kubelet
                  grants exclusive whole cores. No plugin needed. Requires the
                  cluster installed with kubernetes_cpu_policy=kubelet-static.
  best-effort     No pinning; the CFS scheduler places threads.
